How To Set Up a Minecraft Server on macOS

  1. Download and install the latest version of Java.
  2. Download the Minecraft server.jar file from the official Minecraft website. If you don't want to make a Vanilla server (instead something like Bukkit, Paper, Spigot, Fabric), just follow the steps that the other versions tell you.
  3. Make a new folder and put the server.jar file inside.
  4. Open TextEdit and create a new file.
  5. Once in it, go to "Format" at the top of the screen and click "Make Plain Text".
  6. Copy and paste into the file the next three lines:
    #!/bin/bash
    cd "$(dirname "$0")"
    java -Xmx2G -jar server.jar nogui
    (set "server.jar to whatever it's called)
  7. Save it as "start.command" in your server folder.
  8. Double click it. It will launch, then instantly fail. This is normal. Meanwhile, it created some folders and a eula.txt file in the server folders. Open eula.txt.
  9. In the file, look for the line that says "eula=false". Set it to true and save it.
  10. Try running it again. It will now create every single file needed.
  11. You're done! If you want to change the settings and display of your server, go to the server.properties file and change the stuff. But for now, it's only available to the people on your WiFi. See how to port forward a bit below!

How To Let Bedrock Players On Your Minecraft Server

  1. We're going to download a plugin/mod called Geyser for our server. First, go to geysermc.org and go to the "Downloads" section.
  2. Download the Geyser and Floodgate files for your server. If your type isn't there or is a vanilla server, this tutorial is useless for you!
  3. Stop your server, put the downloaded files in your mods/plugins folder of your server, then start it again. This will generate configuration files.
  4. Stop the server again and go to the Floodgate configuration folder and copy and paste a file called "key.pem" into the Geyser configuration folder.
  5. Once done, open the config.yml in the Geyser folder.
  6. Under the "bedrock" section, make sure "clone-remote-port" is set to false. Under "java", set the "auth-type" to "floodgate".
  7. Save it. and start the server. Now you're done, and Bedrock players can join!

How To Port Forward Your Minecraft Server on macOS (plus Geyser!)

  1. Go to System Preferences
  2. Click on "Network"
  3. You can turn off your firewall completely if you like, but otherwise, click on "Options". You will see a list of applications and files.
  4. Click the "+" button to add a new rule
  5. If you run your server on Terminal, look for the application in Applications > Utilities. You also have to allow java (you need java installed). Click Cmd + Shift + G and type in "Library/Java/JavaVirtualMachines". Set them both to "Allow incoming connections".
  6. Open Terminal and run "netstat -nr". Look for the IP address that is next to the word "default". Note it down.
  7. Then, type in "ipconfig getifaddr en0" (change to en1 if you use ethernet). Note the number it shows down. This is your Internal IP Address.
  8. Open Safari and enter the Default Gateway. This will take you to your router's admin panel.
  9. Login.
  10. Find the Port Forwarding section (depending on your interface; it might be under "Advanced" or be called "IPv4 Port Mapping". DON'T CHOOSE IPv6!)
  11. Add a new rule.
    12. port 25565
  12. Enter a name, enter the Internal IP Address where it asks, set the protocol to TCP/UDP, and finally, set the internal/external ports to your port number in your server.properties file.
  13. BUT WAIT! ONE PRECAUTION... CGNAT (Carrier-Grade NAT)! If you have it on your router, port forwarding is impossible. To check, look at the WAN settings and check the IPv4 section. If there is an IP address, note it down. It is your public IP. Then, search "what is my ip" and check the IPv4 section. If it's a totally different address, you are unfortunately behind CGNAT. But if it's the same, you are fine!
  14. Anyways, set the WAN name to the one that your IPv4 address was located in WAN settings.
  15. Save the rule. If you run Geyser, make a second rule, the same as the first, but the ports are the ones you find in your config.yml.
  16. Go to a website like mcsrvstat.us and enter the public IP address/DNS and port number. However, a more accurate example is canyouseeme.org. But this example anly shows TCP ports. Look on the web for a UDP port checker.
  17. Now, you can give your friends your public IP address/DNS and the port number to join! If you don't want to give your location though, you can asssign a DNS, which I will show next!

How To Set Up a DNS for Your Minecraft Server for free using Dynu

  1. Go to dynu.com and sign up for a free account.
  2. Go to "DDNS Services" and click on "Add".
  3. Enter a hostname, then choose and ending from "Top Level". It will probably look like hostname.endingtld.tld.
  4. Set the IPv4 address to your public IP address. DO NOT enter anything for IPv6.
  5. Set "Wildcard IPv6 Alias", "Enable IPv6 Address" and "Wildcard IPv4 Alias" to off.
  6. Save the record.
  7. To test, open Terminal and run the command "nslookup your-hostname.tld.tld." (change "your-hostname.tld.tld" to your actual hostname).
  8. If it says something like "Server: [Your Default Gateway], Name: [your DNS], IP Address: [your Public IP Address]" then your DNS is working and your friends can enter your server without figuring your location!
