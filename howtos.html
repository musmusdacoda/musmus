How To Port Forward Your Minecraft Server on macOS (plus Geyser!)

  1. Go to System Preferences
  2. Click on "Network"
  3. You can turn off your firewall completely if you like, but otherwise, click on "Options". You will see a list of applications and files.
  4. Click the "+" button to add a new rule
  5. If you run your server on Terminal, look for the application in Applications > Utilities. You also have to allow java (you need java installed). Click Cmd + Shift + G and type in "Library/Java/JavaVirtualMachines". Set them both to "Allow incoming connections".
  6. Open Terminal and run "netstat -nr". Look for the IP address that is next to the word "default". Note it down.
  7. Then, type in "ipconfig getifaddr en0" (change to en1 if you use ethernet). Note the number it shows down. This is your Internal IP Address.
  8. Open Safari and enter the Default Gateway. This will take you to your router's admin panel.
  9. Login.
  10. Find the Port Forwarding section (depending on your interface; it might be under "Advanced" or be called "IPv4 Port Mapping". DON'T CHOOSE IPv6!)
  11. Add a new rule.
    12. port 25565
  12. Enter a name, enter the Internal IP Address where it asks, set the protocol to TCP/UDP, and finally, set the internal/external ports to your port number in your server.properties file.
  13. BUT WAIT! ONE PRECAUTION... CGNAT (Carrier-Grade NAT)! If you have it on your router, port forwarding is impossible. To check, look at the WAN settings and check the IPv4 section. If there is an IP address, note it down. It is your public IP. Then, search "what is my ip" and check the IPv4 section. If it's a totally different address, you are unfortunately behind CGNAT. But if it's the same, you are fine!
  14. Anyways, set the WAN name to the one that your IPv4 address was located in WAN settings.
  15. Save the rule. If you run Geyser, make a second rule, the same as the first, but the ports are the ones you find in your config.yml.
  16. Go to a website like mcsrvstat.us and enter the public IP address/DNS and port number. However, a more accurate example is canyouseeme.org. But this example anly shows TCP ports. Look on the web for a UDP port checker.
  17. Now, you can give your friends your public IP address and the port number to join! If you don't want to give your location though, you can asssign a DNS, which I will show next!
