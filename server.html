So, you want to join? Here's how for each device:

Java Edition (PC, Mac, Linux)

To join, simply open Minecraft, click "Multiplayer", then "Add Server", and enter the following details:

Server Name: MUSA'S ULTIMATE SERVER (or anything else you like)

Server Address: musaserver.ddnsfree.com:20815

Then click "Done", and you should see the server in your list. Click on it and then "Join Server" to start playing!

NOTE: YOU MUST HAVE THE FABRIC LOADER AND API TO JOIN!

To join, open Minecraft on your mobile device, tap "Play", then "Servers", and scroll down to the "Add Server" option. Tap on it and enter the following details:

Server Name: MUSA'S ULTIMATE SERVER (or anything else you like)

Server Address: musaserver.ddnsfree.com

Port: 38809

Then tap "Save", and you should see the server in your list. Tap on it and then "Join Server" to start playing!

Video Game Console (Xbox, PlayStation, Nintendo Switch)

Download "BedrockTogether" on a mobile device and follow the instructions to add the server.

Server Address: musaserver.ddnsfree.com

Port: 38809

Click "Run". This will start a proxy (make sure your console and mobile device are on the same network).

On your console, open Minecraft and go to the LAN game section. You will find the server listed there called "BedrockTogether".

PLAY IT

Anyways, have fun! PS: You have to keep BedrockTogether running in the background while playing. To stop accidental refreshing, go to your system settings on the mobile device. Look for the "BedrockTogether" app and set Background App Refreshing to Off.
